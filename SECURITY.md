# Security policy

## Supported versions

Ermik is a preview. Security fixes target the current `main` branch. When a release is published, fixes may also target the latest release; older snapshots and forks are not maintained. Check the current code before reporting an issue already fixed on `main`.

## Report privately

Use [Report a vulnerability](https://github.com/greggubarev/ermik/security/advisories/new) to send a private report through GitHub Security Advisories. Include the affected commit or release, impact, reproduction steps, and a minimal proof of concept. Do not post exploit details, credentials, tokens, private repository data, or other sensitive material in public Issues, pull requests, or discussions. Revoke any exposed credential immediately.

Repository maintainers triage reports in the private advisory, verify the affected versions, coordinate a fix, and keep confirmed details private until disclosure is appropriate. After a fix is available, they may publish an advisory and link a release note or public issue that does not expose secrets. No fixed response time or backport schedule is promised.
